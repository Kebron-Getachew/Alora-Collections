# Alora Jewelry 

A fully responsive e-commerce website designed and developed for a jewelry small business.

## Overview

Alora Jewelry is a multi-page online store built with React, featuring a complete shopping experience from browsing collections to checkout.

## Pages

- **Home** — landing page and brand introduction
- **Collections** — product browsing and catalog
- **Cart** — add and manage selected items
- **Checkout** — order completion flow
- **About** — brand story
- **Contact** — customer inquiries

## Tech Stack

- React
- React Router (navigation)
- CSS / Tailwind
